# Axottle Academy Content

Учебные материалы для **Axottle Academy**.

Контент хранится в Markdown, чтобы изменения можно было версионировать, ревьюить и обновлять вместе с Axottle.

## Структура

```text
courses/
└── 01-first-launch/
    ├── 01-welcome.md
    └── assets/
```

## Правила контента

- Один урок — один `.md` файл.
- Скриншоты и схемы курса хранятся в `assets/` рядом с уроками.
- Academy объясняет, **как выполнить задачу на практике**; полные справочные детали остаются в `docs.axottle.com`.
- Один скриншот должен показывать одно основное действие или состояние.
- Секреты, реальные токены, IP-адреса и другие чувствительные данные на скриншотах должны быть скрыты.
